# 📂 ScreenPen Assets

This directory contains the visual assets for the ScreenPen application.

## 🖼️ Included Images
- `icon.png`: High-resolution logo for the application.
- `Capture_*.png`: Demonstration screenshots of the interface in action.

## 🎨 Themes
The application uses these assets to render:
- **Glassy Transparency**: Applied dynamically via GDI+.
- **Adaptive Icons**: Icons change color based on the Light/Dark mode settings.

Refer to the [Main README](../README.md) for full project details.
